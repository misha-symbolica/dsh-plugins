## `transcript_find`

List or look up DSH sessions (any workspace) by title, workspace, id or age, so another agent's transcript can be inspected with the other transcript_* tools. Returns id, workspace/title, creation time and whether the session is live. Costs no log reads unless details:true (then also model, cwd, event/call/error counts and the number of registered tools per session).

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | no | Case-insensitive substring over "workspace/title" and id (e.g. "tensatory", "slider", "2b81"). Omit to list everything. |
| `workspace` | string | no | Only this workspace (basename of the working directory, e.g. "tensatory"). |
| `since` | string | no | Only sessions created at/after this ISO date/time or within a relative window like "7d", "12h" (applies to sessions/"*" selections). |
| `until` | string | no | Only sessions created before this ISO date/time (or "7d" = seven days ago). With since this brackets a cohort. |
| `details` | boolean | no | Read each listed session and add model, cwd, events, calls, errors and registered-tool count (one log read per session; the listing itself stays cheap without it). |
| `limit` | integer | no | Maximum rows (default 20). |
| `fmt` | "text" \| "json" \| "jsonl" | no | text (default, compact) \| json (whole canonical object) \| jsonl (header object, then one object per row). |
| `out_file` | string | no | Write the complete rendering (size limits lifted) to this file (relative to the session cwd; same sandbox rules as the write tool) and reply with a summary + 5-line head instead. |

**Returns:** `{ query, total, truncated, sessions[{ id, workspace, title, cwd, createdAt, live, depth, parent, self }], hint? }` rendered as an `id  workspace/title  created  live` table

With `out_file` the canonical value is instead the handle `{ kind: "file", path, lines, bytes, fmt, preview[] }`, rendered as `wrote N lines, X KB (fmt=…) to <path>` plus a 5-line head preview.

## `transcript_outline`

Per-turn table of contents of one session: for each turn its seq range, duration, step and tool-call counts (with error counts per tool), how the turn ended (completed / error with the provider message / aborted / open), and the user prompt. Start here, then zoom in with transcript_read using the seq ranges.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `session` | string | no | "<workspace>/<title>" (e.g. "tensatory/interval-slider-proto"), a title, an id or id prefix, "latest:<workspace>", or omit for this session. Ambiguity lists the candidates. |
| `turns` | string | no | Only these turns, e.g. "4" or "3-6". Default: all. |
| `max_prompt_chars` | integer | no | Prompt excerpt length per turn (default 160). |
| `max_chars` | integer | no | Inline size budget for the rendering (default 24000); later turns are omitted with a continuation hint. Lifted by out_file. |
| `fmt` | "text" \| "json" \| "jsonl" | no | text (default, compact) \| json (whole canonical object) \| jsonl (header object, then one object per row). |
| `out_file` | string | no | Write the complete rendering (size limits lifted) to this file (relative to the session cwd; same sandbox rules as the write tool) and reply with a summary + 5-line head instead. |

**Returns:** `{ session{ id, workspace, title, cwd, createdAt, live, model, provider, events, turns, calls, errors }, turns[{ turn, seqFrom, seqTo, startedAt, ms, steps, calls[{ tool, count, errors }], totalCalls, errors, retries, ended{ kind, code?, message? }, tokens{ output, input, cacheRead, contextEnd }, prompt, lastAssistant }], omitted? }` rendered as one `T<n>  seq a–b  time  duration  steps  calls  tool counts  [tokens]  ended:` line plus the prompt per turn

With `out_file` the canonical value is instead the handle `{ kind: "file", path, lines, bytes, fmt, preview[] }`, rendered as `wrote N lines, X KB (fmt=…) to <path>` plus a 5-line head preview.

## `transcript_read`

Render part of a session as a compact timeline: one line per event — USER / ASSISTANT text, CALL tool args, RESULT ✓/✗ with wall latency, error code and a result excerpt, images as <image W×H type size>, turn markers with how the turn ended. Filter by turn or seq range, by tool name globs, or errors only. raw:true (json/jsonl only) emits the original event objects instead — with out_file that exports the decoded log for shell/python work.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `session` | string | no | "<workspace>/<title>" (e.g. "tensatory/interval-slider-proto"), a title, an id or id prefix, "latest:<workspace>", or omit for this session. Ambiguity lists the candidates. |
| `turn` | integer | no | Only this turn (see transcript_outline). |
| `seq_from` | integer | no | First event seq to include. |
| `seq_to` | integer | no | Last event seq to include. |
| `tools` | string[] | no | Only calls/results of these tools; globs allowed ("chrome_*", "*_screenshot"). User/assistant text and turn markers stay. |
| `errors_only` | boolean | no | Only failed calls (their CALL, RESULT and the assistant text right after), plus turn markers and prompts. |
| `include` | "args" \| "results" \| "assistant" \| "reasoning" \| "injections" \| "all"[] | no | Row classes to include. Default: args, results, assistant. Add "reasoning" for model reasoning blocks and "injections" for plugin/AGENTS.md context injections and the system prompt; "all" for everything. |
| `max_result_chars` | integer | no | Excerpt length per text (default 400). Full text of one event: transcript_event. |
| `max_chars` | integer | no | Inline size budget (default 24000); later rows are omitted with a seq_from continuation hint. Lifted by out_file. |
| `raw` | boolean | no | Emit original event objects (json/jsonl only) instead of timeline rows. |
| `fmt` | "text" \| "json" \| "jsonl" | no | text (default, compact) \| json (whole canonical object) \| jsonl (header object, then one object per row). |
| `out_file` | string | no | Write the complete rendering (size limits lifted) to this file (relative to the session cwd; same sandbox rules as the write tool) and reply with a summary + 5-line head instead. |

**Returns:** `{ session, range{ seqFrom, seqTo, turn? }, filters?, maxResultChars, raw, events[{ seq, kind, time, turn?, step?, tool?, callId?, args?, argsChars?, ok?, ms?, code?, reason?, ended?, plugin?, type?, text?, textChars?, images?[{ w, h, type, bytes, name? }] }], omitted?{ count, seqFrom, seqTo } }` (with `raw: true` the events are the original log events) rendered one line per row: `[seq] USER|ASSISTANT|CALL|RESULT ✓/✗ latency|── T<n> start/end ──`

With `out_file` the canonical value is instead the handle `{ kind: "file", path, lines, bytes, fmt, preview[] }`, rendered as `wrote N lines, X KB (fmt=…) to <path>` plus a 5-line head preview.

## `transcript_tool_stats`

How tools behaved for the agent(s) in one or many sessions: per tool the call count, error count and rate, sessions that used it vs sessions where it was registered (adoption), p50/p90 wall latency, the most frequent error messages (normalized so one bug is one row, with an example session/seq in json) each with the agent's reaction (the reasoning/assistant text right after the failure), and what the agent did next (retry identical, retry changed, switch tool). Opt-in sections: before_error, sequences (tool bigrams/trigrams), runs (same-tool streaks), duplicates (identical-args repeats), args (parameter shapes). split_at compares the per-tool table before/after a date. Use tools globs like ["chrome_*"] and sessions ["*"] for a corpus-wide view.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `session` | string | no | "<workspace>/<title>" (e.g. "tensatory/interval-slider-proto"), a title, an id or id prefix, "latest:<workspace>", or omit for this session. Ambiguity lists the candidates. |
| `sessions` | string[] | no | Several sessions: session spellings, "<workspace>/*", or "*" for all. Overrides session. |
| `tools` | string[] | no | Only these tools; globs allowed. Default: all tools. |
| `since` | string | no | Only sessions created at/after this ISO date/time or within a relative window like "7d", "12h" (applies to sessions/"*" selections). |
| `until` | string | no | Only sessions created before this ISO date/time (or "7d" = seven days ago). With since this brackets a cohort. |
| `split_at` | string | no | ISO date/time (or "7d"): also report the per-tool table for sessions created before vs at/after this instant, side by side. |
| `sections` | "before_error" \| "sequences" \| "runs" \| "duplicates" \| "args" \| "all"[] | no | Extra analytics: before_error, sequences, runs, duplicates, args, or "all". Default: none beyond the base table, reactions and after-error. |
| `top_errors` | integer | no | Error groups listed per tool (default 5). |
| `reactions` | integer | no | Agent reactions (reasoning/assistant text right after the failure) kept per error group (default 2; 0 disables). |
| `top_sequences` | integer | no | Bigrams/trigrams listed in the sequences section (default 15). |
| `fmt` | "text" \| "json" \| "jsonl" | no | text (default, compact) \| json (whole canonical object) \| jsonl (header object, then one object per row). |
| `out_file` | string | no | Write the complete rendering (size limits lifted) to this file (relative to the session cwd; same sandbox rules as the write tool) and reply with a summary + 5-line head instead. |

**Returns:** `{ scope{ sessions, calls, errors, from, to, tools }, tools[{ tool, calls, errors, errorRate, unanswered, sessions, p50Ms, p90Ms, maxMs, topErrors[{ count, message, codes[], example{ session, seq } }] }], afterError[{ tool, next, relation: same-args|retry|switch|end, count }], sessions[{ id, workspace, title }], skipped[{ id, workspace, title, error }] }` rendered as a per-tool table, the after-error list and the skipped list

With `out_file` the canonical value is instead the handle `{ kind: "file", path, lines, bytes, fmt, preview[] }`, rendered as `wrote N lines, X KB (fmt=…) to <path>` plus a 5-line head preview.

| Parameter | Type | Required | Description |
|---|---|---|---|

## `transcript_export`

Export tool calls (each joined with its result: full parsed args, ok, error code, latency, result text) and optionally user/assistant/reasoning/inject/system rows from one or many sessions as jsonl for offline analysis (python, jq). Every row carries session id and workspace/title, so no header join is needed. Use out_file for anything beyond a few hundred rows; inline output is bounded by max_chars.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `session` | string | no | "<workspace>/<title>" (e.g. "tensatory/interval-slider-proto"), a title, an id or id prefix, "latest:<workspace>", or omit for this session. Ambiguity lists the candidates. |
| `sessions` | string[] | no | Several sessions: session spellings, "<workspace>/*", or "*" for all. Overrides session. |
| `since` | string | no | Only sessions created at/after this ISO date/time or within a relative window like "7d", "12h" (applies to sessions/"*" selections). |
| `until` | string | no | Only sessions created before this ISO date/time (or "7d" = seven days ago). With since this brackets a cohort. |
| `tools` | string[] | no | Only calls of these tools (globs). Default: all tools. |
| `kinds` | "call" \| "user" \| "assistant" \| "reasoning" \| "inject" \| "system"[] | no | Row kinds to export. Default: ["call"] (one row per call, result joined in). |
| `errors_only` | boolean | no | Only failed calls. |
| `max_result_chars` | integer | no | Result text kept per call row (default 400; 0 drops result text, keeping only resultChars). |
| `max_text_chars` | integer | no | Text kept per non-call row (default 2000). |
| `limit` | integer | no | Maximum rows (default 5000). |
| `max_chars` | integer | no | Inline size budget when out_file is not given (default 24000). |

| `out_file` | string | no | Write the complete rendering (size limits lifted) to this file (relative to the session cwd; same sandbox rules as the write tool) and reply with a summary + 5-line head instead. |

**Returns:** (object)
