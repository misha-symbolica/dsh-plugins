# Icon assets

- `lang-*.svg` — copied from tali's pi-web (`~/github/pi-web/src/client/src/icons/`).
- `html.svg` `css.svg` `json.svg` `md.svg` `yaml.svg` — [devicon](https://github.com/devicons/devicon) (MIT), `*-original` variants.
- `toml.svg` `svg.svg` — [material-icon-theme](https://github.com/material-extensions/vscode-material-icon-theme) (MIT).

Mono/dark marks (`lang-rust`, `lang-perl`, `md`, `json`) are silhouette-tinted at
render time via the registry's `tint` field (CSS mask), as pi-web does.
