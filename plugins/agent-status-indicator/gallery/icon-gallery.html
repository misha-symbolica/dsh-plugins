Agent states
🙂
 agent state: waiting No turn running. The idle face at the bottom of the stack.
🤨
 agent state: thinking (rule key 'thinking') A turn is running with no tool call in flight (pi-web glyph).
😶
 agent state: error The session's last agent turn reported an error (lastAgentError).
🔧✋
 agent state: blocked on you A pending interaction (tool approval / question) waits on your input: current tool icon (or 🔧) with a ✋ badge.
